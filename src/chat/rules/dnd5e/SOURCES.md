# DND 5e 规则来源

本模块的 Python 实现为本项目独立编写，没有复制第三方程序代码，也不包含规则书正文。

基础 d20 检定、优势与劣势机制参考 Wizards of the Coast 的《System Reference Document 5.1》（SRD 5.1）及 D&D Basic Rules (2014)。SRD 5.1 由 Wizards of the Coast LLC 提供，并以 [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/) 发布：

- [SRD 5.1（CC BY 4.0）](https://www.dndbeyond.com/attachments/39j2li89/SRD5.1-CCBY4.0_License_live%20links.pdf)
- [D&D Basic Rules (2014)：Using Ability Scores](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/using-ability-scores)
